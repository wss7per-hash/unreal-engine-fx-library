## 1. 产品概述

### 1.1 背景与问题
UE5 项目的特效资产（Niagara / Cascade）散落在各工程的 `Content` 目录里，文件多、依赖隐、版本杂：
- 想复用别人做好的粒子，不知道工程里有哪些、长什么样；
- 复制 `.uasset` 经常"变粉"——漏了递归依赖；
- 没有轻量的浏览/预览工具，每次都要进编辑器、等加载。

### 1.2 目标用户
- **主力**：独立开发者 / 小团队 TA（技术美术），用 UE5.3+ 做游戏，资产量 **几百～几万** 不等。
- **次要**：美术总监做资产盘点、健康体检。

### 1.3 产品定位（一句话）
> 一款**不依赖编辑器插件的桌面客户端**，让你在 UE 之外浏览、预览、整理、迁移 UE5 特效资产。

### 1.4 核心价值主张（诚实版）
1. **免插件浏览**：纯 Python + Qt 客户端，无需在工程里装插件即可看资产。
2. **本地索引库**：SQLite 建立资产清单（类型/标签/收藏/评分/缩略图），离线可用。
3. **安全迁移**：通过 `.fxpack`（标准 `.uasset` + manifest 的自包含 zip）实现"不丢依赖"的跨工程迁移。
4. **资产治理**：标签、收藏、重命名、回收站，把素材库管起来。

### 1.5 非目标（Out of Scope，当前版本明确不做）
下面这些在原型/旧设计文档里出现过，但**经本次 PRD 评审决定砍掉或延期**，避免"名实不符"：

| 砍掉/延期项 | 决策 | 理由 |
|---|---|---|
| **社区市场 / 在线分享** | 🗑 删除 | 与"纯本地客户端、免登录"定位冲突；无后端，做不了 |
| **版本时间线 / 变更历史** | 🗑 删除 | 需监听 UE 工程文件变更，超出客户端范围 |
| **性能档位标注 / GPU 预算可视化** | ⏸ 延期至 v3 | 需引擎内剖析数据，当前仅能静态估算 |
| **缩略图 A/B 对比** | ⏸ 延期 | 依赖"动态渲染"能力，该能力本期降级（见 §3.2） |
| **项目 pill + 渲染源 pill 毛玻璃** | 🗑 删除（已砍） | 与"无插件纯客户端"架构矛盾，确认不做 |
| **"播放 / UE 真实渲染缩略图"** | ⬇ 降级（见 §3.2-③） | 渲染路径是零调用死代码；即便接上每资产冷启动 30–90s 不可用 |

## 2. 现状评估（基于 2026-07-23 深度评测）

> 这一节是"我们在哪"，是 §3 增删决策的事实基础。结论先行：**工程质量高、纯视觉过关，但规模/健壮性/数据完整性脆弱，核心闭环名实不符。**

### 2.1 ✅ 已经能用的（保留）
- 三视图：图标网格 / 列表 / 详细信息（表格，可排序、可拖列宽、有斑马纹、右键复用 grid 菜单）。
- 侧栏导航：全部 / 收藏 / 最近 / 未分类 / 未标签 / 有缩略图 / 无缩略图 / 文件夹树 / 回收站。
- 缩略图：引擎内嵌静态图提取（tier1）、峰值帧（tier2 占位）、手动图（tier3）、统一占位（tier4，渐变+字母）。
- 检查器：类型/标签/评分(星)/备注/来源/操作按钮。
- 标签管理、收藏、导入 `.fxpack`、复制到 Content 文件夹、回收站、i18n（中/英）、深/浅主题、QA 套件（260+ PASS）。

### 2.2 🔴 已经坏的（必须修，对应深度评测 ①②③④⑤⑥⑭）
| 编号 | 问题 | 代码位置 |
|---|---|---|
| ① | 网格零虚拟化：每资产 new 一个 QWidget 全量布局，真实库（万级）直接卡死/OOM | `asset_grid.py:566 set_assets` |
| ② | 重扫静默抹掉用户标签/收藏/评分/备注（`INSERT OR REPLACE` 整行覆盖） | `scanner.py:318` + `database.py:230` |
| ③ | 扫描遇单文件异常 `return` 整轮 abort，库建一半、无续扫 | `scanner.py:332` |
| ④ | `fx_only` 模式把 Unknown 资产直接 `DELETE`，误判即丢资产 | `scanner.py:260` |
| ⑤ | SQLite 无 WAL、无备份；库路径可指向网络盘，崩中易损 | `database.py` 裸 `connect` |
| ⑥ | 任意小操作（删/标 tag/切视图）都全表重读+全网格重建，大库每点必卡 | `main_window.py:1734 _reload_library` |
| ⑭ | 详情表排序后"视觉行≠数据索引"，点开会打开错误资产 | `_on_details_current_changed` |

| 编号 | 承诺 vs 现实 |

| ⑩ | README 承诺"导出 .fxpack" → **UI 完全无入口**，只能导入不能产出 |

### 3.2 删除 / 降级清单（明确砍掉，避免再许空诺）

**③ 缩略图"播放 / UE 真实渲染"能力降级**
- **决策**：从产品承诺中**删除"动态播放缩略图"和"UE 离屏渲染"卖点**。
- **依据**：`_auto_render_thumbs` 全代码零调用（死代码）；即便接上，每资产一次 UnrealEditor 冷启动 30–90s，批量渲染不可用（深度评测 ⑨）。
- **新定位**：缩略图 = ① 引擎内嵌静态图（tier1，纯 Python 提取，已实现）+ ② **手动上传/指定图片**（tier3，已实现）+ ③ 统一占位（tier4）。文案统一为"读取引擎缩略图"，删除所有"播放/真实渲染"字眼。
- **远期候选（v3+，非本期）**：若未来引入"长驻无头 UE 服务"架构，再评估批量渲染，届时单独立项。

**社区市场 / 版本时间线 / 性能档位 / A/B 对比**：见 §1.5，全部移出当前范围。

### 3.3 新增清单（本期要做）

见 §4 各 Epic 的 User Story。重点三件：
1. **虚拟滚动网格**（P0，架构级，决定能否用在大库）。
2. **导出 .fxpack 闭环**（P1，打通"能产出"的核心价值）。
3. **健康扫描 UI**（P1，接上已备好的模块 E）。

### 3.4 保留 / 改名清单
- **"导出到 UE 工程"** → 改名 **"复制到 Content 文件夹"**，文案诚实说明"仅复制文件，不注册进实时工程"。
- 三视图、侧栏导航、检查器、标签、收藏、导入、主题、i18n 全部保留并加固。

## 4. 详细功能需求（按 Epic）

> 每条 User Story 带验收标准（AC）。优先级：P0=阻断可用性，P1=核心闭环/数据，P2=体验打磨。

### Epic A · 资产浏览与虚拟化（P0/P1）

**A-1 虚拟滚动网格（P0）**
- *As a* TA 管理万级资产库，*I want* 滚动浏览不卡死，*so that* 客户端在真实工程可用。
- AC：
  1. 用 `QListView` + 自定义 `QAbstractListModel`/`QStyledItemDelegate` 或等价虚拟化方案，**视口外卡片不实例化**。
  2. 在 ≥20,000 个资产的库上，首屏渲染 < 1s，滚动帧率 ≥ 30fps（测试环境）。
  3. 缩略图走异步加载 + 内存 LRU 缓存，不在主线程解码大图。
  4. 选择/收藏角标/悬停态在虚拟化下正确保持。

**A-2 增量刷新（P1）**
- AC：删除/标 tag/切收藏视图等小操作，**只更新变动行**，不再 `get_assets()` 全表重读 + 全网格重建（修复 ⑥）。

**A-3 搜索防抖（P1）**
- AC：搜索框输入 250ms 防抖后再触发筛选；筛选在虚拟化模型上做，不重建控件（修复 ⑦）。

**A-4 详情表排序正确（P1）**
- AC：排序后点击行，用 `item(row,0).data(UserRole)` 反查 `source_path` 取资产，不再用行索引错位（修复 ⑭）。

### Epic B · 数据完整性与扫描健壮性（P0/P1）

**B-1 重扫保留用户数据（P0）**
- AC：`upsert_asset` 只覆盖扫描可得字段（type/size/thumb/tier/has_thumb），**保留** tags/favorite/rating/note（修复 ②）。写入前先 `get_asset` 合并旧用户字段。

**B-2 单文件异常不崩整轮（P0）**
- AC：扫描循环 `try/except` 下沉到单文件粒度；异常收集进 `errors` 列表、继续处理其余文件；结束弹"N 个文件失败"汇总（修复 ③）。

**B-3 未知类型保守保留（P0）**
- AC：`fx_only` 模式下 Unknown 资产**不 DELETE**，标记为"未分类"保留；类型识别失败走保守策略（修复 ④）。

**B-4 DB WAL + 自动备份（P1）**
- AC：开 `PRAGMA journal_mode=WAL`；启动时对 `.db` 做时间戳备份（保留最近 3 份）；校验库路径可写（修复 ⑤）。

### Epic C · 资产治理（标签/收藏/重命名/回收站）（P1/P2）

**C-1 按标签筛选（P1）** — 补回原型被砍能力
- AC：侧栏出现"标签"区，列出所有已用标签；点击筛选该标签资产；支持多标签 OR/AND。

**C-2 回收站真实化（P1）**
- AC：删除资产时，**磁盘真实 `.uasset` 移入系统回收站**（带二次确认）；"从目录移除"作为轻量替代选项；copy 模式导入的 `library/files/` 孤儿文件有清理机制（修复 ⑧）。

**C-3 设置入口统一（P1）**
- AC：`_settings` 与 `_open_settings` 合并为同一实现；改 `library_dir` 后统一 `_open_db()` 重开库（修复 ⑮/⑭ 类分歧）。

**C-4 收藏视图联动（P2）**
- AC：在收藏视图取消收藏，若该资产即当前检查器对象，清空检查器（修复 P1-H）。

**C-5 资产重命名（P2）**
- AC：检查器/右键提供重命名，改名同步 `name` 字段与 `source_path` 衍生显示（不影响磁盘文件名，除非用户显式"重命名文件"）。

### Epic D · 导出/导入 .fxpack 闭环（P1）

**D-1 导出 .fxpack（P1）** — 修复 ⑩，打通核心闭环
- *As a* TA，*I want* 把选中的特效打包成 `.fxpack`，*so that* 别人导入后不丢依赖。
- AC：
  1. 工具栏/检查器/右键均有"导出为 .fxpack"入口。
  2. 自动递归收集依赖（材质/贴图/蓝图等），写入 `manifest.json`（含原始 package path、类型、缩略图引用）。
  3. 打包进标准 zip（内部 100% 标准 `.uasset`），沿用现有导入逻辑可还原。
  4. 若依赖解析失败，给出明确警告清单，不静默丢依赖。

**D-2 导入 .fxpack（已有，加固）**
- AC：保留现有解包+写库；导入后缩略图正确显示；重复导入有冲突提示。

**D-3 "复制到 Content 文件夹"改名（P2）**
- AC：原"导出到 UE 工程"按钮更名，文案声明"仅复制文件、不注册进实时工程"（修复 ⑬）。

### Epic E · 健康扫描 UI（P1）

**E-1 体检入口与报告（P1）** — 接上模块 E（修复 ⑪）
- AC：
  1. 工具栏加"体检"按钮，触发 `bridge/fx_health.py`（缺失依赖 / 重复资产 / 潜在变粉）。
  2. 结果以可点击报告呈现（点击跳到对应资产）；检查器加"健康"行展示该资产状态。
  3. 死 i18n 键（health 排序/筛选/检查器键）要么接上要么删除（修复 P2-I）。

### Epic F · 搜索/筛选/排序增强（P1/P2）

**F-1 搜索防抖** — 见 A-3。
**F-2 排序选项补全（P2）** — 若接 E-1，排序/筛选 combobox 补"健康度"项，并与 `health` 字段联通。
**F-3 日志 Dock 标题统一（P2）** — 初启"UE 桥日志"与切语言后"活动日志"统一为一个 i18n 键（修复 P1-E）。

### Epic G · 缩略图诚实化（P2）

**G-1 文案纠偏（P2）** — 见 §3.2-③：删除所有"播放/UE 真实渲染"字眼，统一为"读取引擎缩略图"+手动上传；删除 `_auto_render_thumbs` 死代码或标注为未启用。

## 5. UI / UX 设计规范

├──────────┬──────────────────────────────────────────────────┤
│ 侧栏      │  内容区（content_stack）                          │
│ ├ 快捷    │  ├ 内容头：标题 + 计数 + 选择提示 + 批量条       │
│ │ 全部    │  ├ [图标网格 | 列表 | 详细信息]                  │
│ │ 收藏    │  └ 空态 / 加载态 / 错误态                       │
│ │ 最近    │                                                  │
│ ├ 筛选    │  检查器（右侧抽屉/停靠）                          │
│ │ 未分类  │  ├ 缩略图 + 名称 + 类型徽章                     │

### 5.2 布局规范
- **整体**：左固定侧栏（~240px，可折叠）+ 中内容区（弹性）+ 右检查器（~320px，可选停靠）。顶部工具栏 + 底部状态/日志 Dock。
- **侧栏上方空白（修复 P1-J）**：去掉约 200px 垂直 splitter 死区，把"快捷筛选 + 标签区 + 文件夹树"合并为单一自然流滚动容器。
- **选择提示（修复 P2-N/O）**：`sel_hint` 默认隐藏，进入选择态才显示；回收站视图下换用"清空回收站"语境文案。

### 5.3 组件规范
| 组件 | 规范 |
|---|---|
| 卡片（图标视图） | 缩略图 + 名称 + 类型渐变徽章 + 收藏角标（hover 显示，已收藏常驻）；圆角 8px，hover 微抬升 |
| 表格（详情视图） | 6 列：名称/类型/标签/大小/来源/评分；斑马纹；列宽可拖；列头点击排序带箭头；行高固定 |
| 评分星 | **正方形 28×28 按钮**，无焦点框（`#star:focus{outline:none}`）；★ 琥珀色 / ☆ 灰；点击切分 |
| 次级按钮 | `#secondary` 带 `border-radius:8px` + 合理 padding（修复"方矩形"问题） |
| 对话框/Lightbox | 遮罩按主题 token，禁止硬编码 `rgba(...)`（修复 P2-M） |
| 日志 Dock | 单一 i18n 标题，初启与切语言一致（修复 P1-E） |
| 菜单/右键 | 复用 `style.py` token，不内联（修复 P2-M） |

### 5.4 三视图规范（已实装，固化）
- **图标**：缩略图网格（虚拟化后见 A-1）。
- **列表**：单行紧凑列表（名称+类型+缩略图小图）。
- **详细信息**：上表表格，与图标视图选择联动（选中↔检查器↔网格三方同步）。

### 5.5 交互与状态
- **空态**：对应视图无结果时，显示图标 + 一句引导（如"这个筛选没有资产"）。
- **加载态**：扫描/渲染进行中显示进度（非模态进度条，可取消）。
- **错误态**：单文件扫描失败走 B-2 汇总，不弹中断；UE 桥失败显示日志 Dock 红色条目。
- **选择态**：卡片 checkbox / 表格整行选中；批量条露出（复制/导出/删除/加标签）。

### 5.6 主题
- 沿用深/浅双主题 token（`style.py`）；切换时强制 re-polish（已实现）。
- 视觉风格：**清爽柔光渐变（Stripe 风）**，类型徽章按 Niagara/Cascade/Blueprint/Texture/Material 用不同渐变区分。

## 6. 非功能性需求

| 维度 | 要求 |
|---|---|
| **规模/性能** | 支持 ≥50,000 资产库流畅浏览（虚拟滚动，A-1）；任意单操作不触发全量 reload（A-2）；搜索防抖（A-3） |

## 9. 风险与开放问题

1. **A-1 虚拟滚动改造工作量最大**：需替换 `AssetGrid` 渲染模型，可能影响现有卡片交互，建议独立分支 + 回归 QA 守护。
2. **D-1 依赖解析准确性**：依赖收集依赖 UE 桥脚本 `fx_export`，需验证递归深度与循环引用处理。
3. **C-2 系统回收站跨平台**：当前仅 Windows，mac/Linux 回收站 API 不同，本期若只保 Windows 需在文档声明。
4. **E-1 健康扫描依赖 UE 桥**：体检需拉起无头编辑器，冷启动 10–30s，是否默认手动触发而非自动，需定。
5. **B-4 网络盘库路径**：若用户坚持把库放网络盘，WAL 仍可能不安全，文档需建议本地盘。

## 附录 · 术语表

- **.fxpack**：标准 `.uasset` 集合 + `manifest.json` 的自包含 zip，用于跨工程安全迁移。
- **tier**：缩略图来源层级（1=引擎内嵌静态 / 2=峰值帧占位 / 3=手动 / 4=统一占位）。
- **has_thumb**：1=真有内嵌图，0=仅占位。
- **虚拟化**：仅实例化视口内元素的列表/网格渲染技术，避免万级 QWidget 卡死。
- **UE 桥**：`bridge/` 下运行在 UnrealEditor 内的 Python 脚本，做引擎敏感操作（列资产/渲染/导入导出/体检）。
